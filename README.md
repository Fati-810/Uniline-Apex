# Uniline Apex | Industrial Products Business Website

A custom-coded, responsive business website developed for Uniline Apex, a supplier of industrial rubber and pneumatic products.

## Key Features

- Responsive design for desktop, tablet, and mobile devices.
- Multi-page business website architecture.
- Organized industrial product catalog with dedicated product pages.
- Interactive hero slider and brand showcase.
- Mobile-friendly navigation and responsive product grids.
- Contact enquiry form integration.
- WhatsApp, Google Maps, and direct contact links.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Development & Deployment

- Custom front-end development.
- Responsive layout implementation.
- Product catalog organization.
- Domain and hosting configuration.
- DNS and SSL/HTTPS setup.
- Website testing and deployment.
